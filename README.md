# Car Dealership Inventory System

Full-stack TDD kata: Node/Express + PostgreSQL (Prisma) backend, React (Vite) frontend.

## Local setup

Backend setup, migrations, seeding, tests, and coverage are documented in [`backend/README.md`](backend/README.md). Frontend setup will be added when the frontend is built.

### Database (Docker)

```bash
docker compose up -d
```

- Dev DB: `postgresql://postgres:postgres@localhost:5432/dealership_dev`
- Test DB: `postgresql://postgres:postgres@localhost:5432/dealership_test`
